IST 210 - Organization of Data

This is a second-year database course for many majors at Penn State's College of IST.

What will you learn?

This course teaches an introduction to SQL, along with the proper manner of storing data as needed, this course has a heavy focus on creating a database from scratch. Along with proper programming when using software such as Microsoft SQL Server

Are there any prerequisites or classes after?

While there are no prerequisites, there are a variety of classes that require a strong knowledge of the subject afterward. Some of these courses include IST 260W, ETI 300W, and its follow-up course, ETI 461.

IST 220 - Networking and Telecommunications

This is a second-year course for many majors at Penn State's College of IST.

What will you learn?

This course focuses on an introduction to networking, where students will learn what the internet really is while also beginning to understand how to set up and manage a structured network environment for businesses.

Are there any prerequisites or classes after?

Like IST 210, there are no required courses before taking this course. However, there are a variety of courses that this leads into, notably IST 226, which is Networking Essentials. This then leads to IST 227 and IST 228, which are both advanced networking courses. course is a fundamental part of the certificate along with the degree.
