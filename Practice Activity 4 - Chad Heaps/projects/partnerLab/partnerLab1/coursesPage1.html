IST 110: Information, People and Technology

This is a first-year introductory course for many majors at Penn State's College of IST. The purpose of this class is to explore how we use technology, how it integrates with human enterprises, and how it helps people and organizations.

What will you learn in IST 110?

IST 110 provides an introduction to Information Science and Technology and informs you of how that technology is used daily in different environments. It also teaches basics of how data is stored, and how it is organized as well.

Are there any prerequisites or classes after?

There are no prerequisites for this class, since it is a first-year, entry-level class that provides a basic understanding of the IST program. This class can provide entry into the four-year IST degree program.

IST 250: Introduction to Web Design and Development

This is a second-year course for many majors at Penn State's College of IST.

What will you learn in IST 250?

IST 250 provides an introduction to the visual and information design of websites and the technologies of the internet. After completing this class, students will have an understanding and working knowledge of what the web is, how important web content is, and how web content can be hosted and delivered.

Are there any prerequisites or classes after?

IST 250 doesn't have any prerequisites. This class can be applied toward Penn State's two-year IST degree program.
